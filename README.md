# Gather.io

A Unity 3D project developed by Jasuke Studio using the Universal Render Pipeline (URP).

## Project Overview

Gather.io is a 3D game/application built with Unity using the Universal Render Pipeline template. This project serves as a foundation for developing cross-platform games with optimized rendering performance.

## Features

- Built with Unity's Universal Render Pipeline (URP) for efficient rendering
- Cross-platform compatibility (PC, Mobile, Console)
- Optimized for performance across different devices
- Includes terrain and material systems
- Input system integration
- UI framework with TextMesh Pro

## Project Structure

- `Assets/`: Core game assets including scripts, scenes, materials, and art
  - `Animasi/`: Animation files
  - `Art/`: Art assets and textures
  - `Materials/`: Material definitions
  - `Prefab/`: Prefab objects
  - `Scenes/`: Game scenes
  - `Scipts/`: C# scripts
  - `Settings/`: Project settings
  - `Shadergraph/`: Custom shaders
  - `TerrainData/`: Terrain data assets
  - `TextMesh Pro/`: Text rendering system
- `Packages/`: Unity package dependencies
- `ProjectSettings/`: Unity project configuration

## Requirements

- Unity 2022.3 LTS or higher (compatible with URP)
- Compatible with Windows, macOS, and Linux

## Getting Started

1. Open the project in Unity Hub
2. Select the project and click "Open"
3. The project will open in the Unity Editor
4. Navigate to `Assets/Scenes/` to find the main scene
5. Press Play to run the project in the editor

## Build Instructions

1. Go to File → Build Settings
2. Select your target platform
3. Click "Build and Run" to create an executable

## About URP (Universal Render Pipeline)

This project uses Unity's Universal Render Pipeline which provides:
- Fast, scalable rendering for all platforms
- Artist-friendly tools and flexible, modern architecture
- A customizable pipeline that you can modify to meet your project's specific needs
- A library of pre-built render features and components that you can use out of the box
